1. Sandbox setup checklist

    Server setup instructions

    Privately set PAYPAL_SANDBOX_CLIENT_ID, PAYPAL_SANDBOX_CLIENT_SECRET and PAYPAL_SANDBOX_WEBHOOK_ID on the server. Never enter credentials in these forms.

    Configure the sandbox webhook at /api/payments/paypal/webhook on your public HTTPS deployment. Run billing_worker.py as a separate supervised, always-on service. Browser tabs do not run payment retries.

    2. Prices & tier features

    Set monthly and annual prices in USD for all four tiers. Existing subscriptions retain their original price. Changing prices requires preparing new plans before billing can be enabled.
